## Rules for future fault injection

Use only synthetic identities in separately approved hnc_step15q_sandbox. No worker, DB failpoint, process kill, load tool, server, network or email action ran in this phase. Plan barriers around reads/commit/acknowledgement rather than relying on sleep timing. Record per-command IDs, revisions and domain invariant counts without tokens/OTP/credentials/PII. Inject callback failure, duplicate delivery, retryable conflict, timeout, connection loss and unknown commit result separately. Do not blindly retry a nondeduplicated request after an unknown commit. Real rollback/majority/write-conflict assertions require a real isolated replica set and remain BLOCKED.

Successful invariants require **zero** duplicate awards, redeemed claims, terminal transitions, consumed OTPs, audit omissions or unauthorized mutations. Request rejections/conflicts are expected outcomes, not automatically operational failures; track their codes separately from unhandled500s. Shared-engine tests do not establish legacy endpoint behavior, and no private allocation transaction is part of any approved test plan here.
